# Reader v0.3 可靠阅读实施计划

## 阶段一：状态与导航

1. 将阅读进度升级为按章节存储的 v2 模型，并兼容迁移旧数据。
2. 修改 App 使用独立的 `scrollOffset` 和 `pageIndex`。
3. 将章节切换区分为 push、replace、popstate 三种来源。
4. 将章节目录改为真实链接，同时保留客户端无刷新切换。
5. 新增进度迁移、模式切换、URL 历史和返回导航测试。

## 阶段二：分页与键盘

1. 为 Paginator 增加受控键盘翻页入口。
2. 翻页模式左右键翻页，滚动模式左右键换章。
3. 交互控件获得焦点时忽略全局快捷键。
4. 新增页内翻页、跨章边界和输入焦点测试。

## 阶段三：数据请求

1. 为目录和章节请求增加 AbortController。
2. 将章节缓存改为有界 LRU。
3. 当前章成功后预取相邻章节。
4. 新增竞态取消、缓存淘汰和预取测试。

## 阶段四：主题与无障碍

1. 在应用启动前同步初始化主题、color-scheme 和 theme-color。
2. 抽取可复用 dialog 行为，实现 Esc、焦点进入、锁定与恢复。
3. 补齐 BottomSheet、Sidebar 和 Tabs 的语义与键盘操作。
4. 增加 skip link、正文焦点与 aria-live 状态。
5. 加入统一 focus-visible 和 reduced-motion 样式。

## 阶段五：验证

1. 运行 `pnpm test`。
2. 运行 `pnpm build`。
3. 检查移动端滚动、翻页、旋转与安全区。
4. 检查桌面端链接、键盘、前进后退和主题首屏。
5. 审阅 Git diff，确保不纳入小说正文和调试截图。
