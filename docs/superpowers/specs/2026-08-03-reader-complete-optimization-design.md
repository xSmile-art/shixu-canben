# 《时序残本》阅读器完整修复与优化设计

## 1. 项目目标

将 `reader/` 从功能型在线阅读器升级为适合长期连载、移动阅读和追更传播的作品站。优化遵循三个优先级：先保证阅读状态可靠，再补齐追更体验，最后建设长篇内容发布与数据闭环。

## 2. 设计原则

1. 阅读不中断：换章、切换模式、刷新、前进后退和弱网场景均可恢复。
2. URL 是章节状态的权威入口，浏览器原生导航必须有效。
3. 默认界面保持安静，常用功能前置，高级设置收纳。
4. 移动端优先，并完整支持键盘、屏幕阅读器和减少动画偏好。
5. 内容与应用同源发布，GitHub Raw 只作为可选回退。
6. 所有持久化数据带版本，允许向后迁移。
7. 不采集可识别个人身份的数据。

## 3. v0.3：可靠阅读

### 3.1 阅读进度模型

将滚动位置与分页位置分离，并按章节保存：

```ts
interface ChapterProgress {
  scrollOffset: number;
  pageIndex: number;
  updatedAt: number;
}

interface ReadingProgressV2 {
  version: 2;
  currentChapter: number | null;
  chapters: Record<string, ChapterProgress>;
}
```

旧版 `{ num, scrollTop }` 自动迁移：当前章保留 `scrollOffset`，`pageIndex` 初始化为 0。切换阅读模式时分别恢复对应位置，互不覆盖。

### 3.2 URL 与浏览器历史

- 选择新章节使用 `history.pushState`。
- 初始化及内部位置修正使用 `replaceState`。
- 监听 `popstate`，根据 `?ch=` 切换章节。
- 目录章节使用真实 `<a href>`，点击时由应用接管，保留新标签页和复制链接能力。
- 无效章节参数回退到最近阅读章或第一章，并修正 URL。

### 3.3 键盘行为

- 滚动模式：左右键切换章节。
- 翻页模式：左右键翻页，越过边界时才跨章。
- 输入框、滑块、按钮、链接、选择器及可编辑元素获得焦点时，不触发全局阅读快捷键。
- 分页器暴露命令接口或受控回调，统一处理点击、手势和键盘翻页。

### 3.4 网络与缓存

- 章节和目录请求使用 `AbortController`。
- 当前章成功后预取相邻章节，优先下一章。
- 章节缓存使用有上限的 LRU，避免长篇阅读无限增长。
- 错误信息包含重试动作和可执行建议。

### 3.5 主题首屏

- React 启动前读取保存主题并写入 CSS 变量，避免闪白。
- 同步 `color-scheme` 和 `<meta name="theme-color">`。
- 运行时切换主题时继续更新浏览器主题色。

### 3.6 弹层与无障碍

- BottomSheet 和移动目录具备 dialog 语义、标题关联、焦点进入、焦点锁定、Esc 关闭与焦点恢复。
- 弹层打开时背景内容不可交互，滚动不穿透。
- Tabs 使用 tablist/tab/tabpanel 语义并支持方向键。
- 页面提供“跳到正文”链接；换章后章节标题可聚焦。
- 加载、错误和页码变化使用适度的 `aria-live`。
- 所有交互控件具有统一 `focus-visible` 样式。

## 4. v0.4：追更体验

### 4.1 作品首页

首页展示封面、简介、标签、章节数、总字数、更新时间、核心卖点、最近更新、“开始阅读”和“继续阅读”。阅读页继续使用 `?ch=N` 深链。

### 4.2 阅读状态

- 目录展示已读、新章和当前章状态。
- 提供本章进度、字数、发布时间和预计剩余阅读时间。
- 最近阅读章拥有明确的“继续阅读”入口。

### 4.3 书签与反馈

- 支持章节书签和段落书签。
- 错别字反馈携带章节号、选中文本和段落标识。
- 分享功能复制当前章节深链，并配置 Open Graph 元信息。

### 4.4 更新订阅

先提供 RSS/Atom；浏览器通知作为后续可选能力，不在未授权时主动申请权限。

## 5. v0.5：长篇与离线能力

- 目录按卷折叠，当前卷自动展开，当前章滚入视图。
- 支持按章节号和标题搜索。
- 大于 50 项的章节列表使用虚拟化或 `content-visibility`。
- 提供 Web App Manifest、Service Worker、已读章节离线缓存和下一章预缓存。
- 离线状态明确展示缓存版本与更新时间。

## 6. v0.6：发布与反馈闭环

### 6.1 内容构建

构建脚本扫描正文目录，生成带版本号的同源内容：

```text
dist/content/index.json
dist/content/chapters/001.md
```

索引包含章节号、标题、卷、字数、发布时间、更新时间和内容哈希。

### 6.2 CI 校验

- 章节编号连续且无重复。
- 文件名、Markdown 标题和索引一致。
- Markdown 可渲染且不含危险 HTML。
- 检测异常标点、空章节和正文自我引用。
- Reader 单测、类型检查和构建全部通过后才部署。

### 6.3 匿名数据

仅统计章节打开、读完、下一章点击、退出区间、继续阅读和阅读模式等聚合事件。提供隐私说明，不记录正文选择、书签内容或可识别身份信息。

## 7. 性能设计

- 分页测量改为批量 DOM 写入、集中布局读取。
- 分页结果按内容哈希、容器尺寸和排版参数缓存。
- 重新分页使用非阻塞状态，保留当前阅读锚点。
- 滚动监听使用 passive，并避免因进度对象变化反复绑定。
- 设置 CSS 变量实时更新，localStorage 延迟持久化。

## 8. 安全设计

- Markdown 禁止原始 HTML 或在渲染后清洗。
- 限制链接协议，外链增加安全属性。
- 部署基本 Content Security Policy。
- 作品内容默认受信，但不将仓库权限当作唯一安全边界。

## 9. 验收标准

### v0.3

- 两种阅读模式切换后分别恢复正确位置。
- 刷新、前进、后退、深链和跨章均落在正确章节。
- 翻页模式方向键不再跳过整章。
- 快速换章不会由旧请求覆盖新内容。
- 深色主题首屏无明显白闪。
- 弹层通过键盘完成打开、操作和关闭，焦点返回触发控件。
- 既有测试、新增专项测试和生产构建全部通过。

### 后续版本

- 每个版本独立发布，不要求等待完整路线图全部完成。
- 新能力必须有测试、失败状态、迁移策略和移动端验收。

## 10. 非目标

- 本轮不引入账号系统、付费、评论社区或复杂后台。
- 不在 v0.3 重做视觉风格。
- 不修改小说正文与创作台账。
- 不在没有真实数据前做复杂推荐算法。
