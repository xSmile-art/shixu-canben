# 《时序残本》第3—20章深度精修设计

## 目标

以第1—2章为语言基准，深度精修第3—20章，使正文恢复冷峻、缜密、自然流畅的叙述质感，同时完整保留既有剧情、设定、人物关系和伏笔。

精修后的正文应减少机械断句与重复解释，增强动作连续性、人物情绪和对白辨识度，但不得借润色之名改变故事走向。

## 范围

- 修改范围：`novels/时序残本/正文/第003章-残本.md` 至 `第020章-异常上升.md`。
- 参照文本：第1—2章，仅作为风格标尺，本轮不修改。
- 权威设定源：`00-记忆台账.md`、人物卡、人物关系台账、伏笔台账与既有大纲。
- 本轮不新增章节，不推进第21章，不修改阅读器代码。

## 精修尺度

允许：

1. 重写不自然的句子和段落。
2. 调整同一场景内的信息顺序，使推理与动作衔接更自然。
3. 压缩重复解释、重复判断和功能相同的对白。
4. 补充必要的动作、环境反馈、身体反应与情绪过渡。
5. 调整段落长度和停顿，使其适合移动端阅读。
6. 在不改变信息含义的前提下，强化章节开头推进、核心发现、爽点与结尾钩子。

禁止：

1. 改变事件结果、因果链或章节里程碑。
2. 删除、替换或提前回收已登记伏笔。
3. 新增能力、组织、人物关系、关键线索或世界规则。
4. 改变人物立场、能力等级、已知信息范围或时间线。
5. 将沈砚写成莽撞、滥情或依靠无限回溯解决问题的人。
6. 为追求文采加入不服务剧情、人物或悬念的装饰性描写。

## 风格基准

### 叙述

- 第三人称限知，始终跟随沈砚的认知范围。
- 冷峻而不僵硬，短句用于落锤与危险瞬间，不连续滥用。
- 情绪优先落在动作、感官与职业判断中，减少直接解释情绪。
- 职业细节服务推理，避免把结论重复讲两遍。
- 一般主谓、动宾之间不使用逗号制造停顿。

### 人物口吻

- 沈砚：简洁、准确、习惯从痕迹与因果切入；压力越大，表达越稳定。
- 苏鸢：克制、直接、带职业控制感；情感通过选择和承担显露。
- 姜十七：市井、机警、有灰色幽默；可有少量停顿，但不以满句碎逗号表现。
- 刻钟：从容、审视、略带答卷式趣味；不写成夸张癫狂反派。
- 林叙白：通过具体记忆和笔迹产生温度，不作为纯粹的线索容器。

## 分批策略

精修按剧情弧进行：

1. 第3—6章：残本确认、官方介入、黑市与恩师残页。
2. 第7—10章：刻钟交锋、版本对比、草稿层与局内立威。
3. 第11—14章：校对员、药剂供应链、清洁工与话语权。
4. 第15—20章：情感并线、老楼、烧盒、活验与扫页人。

每批内部允许调整表达顺序，不跨章搬移关键事件或伏笔。完成一批后再进入下一批，避免后文措辞反向污染前文设定。

## 每章执行流程

1. 对照大纲、记忆台账和伏笔台账列出本章不可丢失信息。
2. 通读正文，标记机械断句、重复说明、对话同质化和情绪跳跃。
3. 完成深度行文重写。
4. 对照原文逐项确认事件、线索、伏笔与章节结尾均被保留。
5. 检查段落、标点、重复句式、人物口吻和移动端可读性。

## 验收标准

- 第3—20章不存在大面积机械碎逗号或明显主谓断裂。
- 人物对白脱离姓名提示后仍具有基本辨识度。
- 每章核心事件、能力信息、伏笔和结尾钩子与原版一致。
- 没有新增未经台账登记的世界设定。
- 叙述质感与第1—2章接近，同时保留后续章节更大的信息量。
- 所有章节通过逐章伏笔核对和全文一致性检查。
- 本轮仅属表达层精修，不更新剧情进度、人物状态和伏笔状态；记忆台账只在确有设定变化时更新，而本设计原则上不产生此类变化。

## 验证与交付

交付前执行：

1. 章节文件完整性和编号连续性检查。
2. 章节字数、逗号密度与异常断句模式扫描。
3. 关键专名、人物名和能力术语一致性搜索。
4. 原文与精修版的章节级信息核对。
5. Git 差异审阅，确认没有修改范围外的用户文件。

最终交付包括精修后的18章正文、分批修改摘要、保留的关键伏笔说明及验证结果。
