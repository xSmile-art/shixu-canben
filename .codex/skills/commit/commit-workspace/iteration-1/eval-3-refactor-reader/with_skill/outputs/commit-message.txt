refactor(reader): 分页组件函数化重构并提取独立hook

将 Paginator 组件从 class 组件重构为函数组件，消除 class 组件的样板代码，使组件结构更简洁。同时将分页计算逻辑抽离为独立的 usePagination 自定义 hook，提升逻辑复用性，并利用 useMemo 缓存分页计算结果，避免不必要的重复计算，优化渲染性能。

变更文件：
- reader/src/components/Paginator.tsx：将 class 组件改为函数组件，使用 useMemo 优化分页计算性能
- reader/src/hooks/usePagination.ts：新增自定义 hook，提取分页计算的纯逻辑，使其可被其他组件复用
